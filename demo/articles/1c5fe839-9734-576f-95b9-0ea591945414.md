## CORS khi deploy tách domain

```java
@Bean
WebMvcConfigurer cors() {
    return new WebMvcConfigurer() {
        @Override
        public void addCorsMappings(CorsRegistry registry) {
            registry.addMapping("/api/**").allowedOrigins("https://app.example.com");
        }
    };
}
```
