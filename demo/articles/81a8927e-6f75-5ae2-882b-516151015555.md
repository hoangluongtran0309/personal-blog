## Checklist trước khi release

- [x] Mọi ảnh có `alt` phù hợp (ảnh trang trí dùng `alt=""`)
- [x] Độ tương phản chữ ≥ 4.5:1
- [x] Không truyền đạt thông tin **chỉ** bằng màu sắc
- [x] Form báo lỗi bằng chữ, gắn với đúng trường
- [ ] Kiểm tra với trình đọc màn hình (NVDA, VoiceOver)

## Dark mode cũng là accessibility

Một số người nhạy cảm với ánh sáng mạnh; một số khác đọc tốt hơn trên nền sáng. Cho người dùng **chọn**, và nhớ lựa chọn đó.

## Motion

```css
@media (prefers-reduced-motion: reduce) {
  * { animation: none !important; transition: none !important; }
}
```
