## Thiết bị thật, mạng thật

Máy dev của chúng ta thường mạnh gấp nhiều lần điện thoại phổ thông. Hãy luôn thử trên **CPU throttling 4x** và mạng *Slow 4G*.

## Ngân sách hiệu năng

| Tài nguyên | Ngân sách |
|---|---|
| JavaScript (nén) | ≤ 170 KB |
| CSS | ≤ 50 KB |
| Ảnh trên màn đầu | ≤ 200 KB |
| LCP | ≤ 2.5 s |

## Những việc làm ngay được

1. Render phía server, JavaScript chỉ để **tăng cường**.
2. Ảnh dùng `loading="lazy"` và kích thước cố định để tránh CLS.
3. Font: `font-display: swap`, chỉ tải các độ đậm cần dùng.

```html
<img src="/images/cover.webp" width="800" height="450" loading="lazy" alt="">
```
