## Ý tưởng

Cùng một trang, người dùng máy mạnh nhận trải nghiệm đầy đủ; máy yếu nhận phiên bản nhẹ hơn nhưng vẫn **dùng được**.

## Tín hiệu có thể dùng

```js
const slow = navigator.connection?.effectiveType?.includes("2g");
const lowMemory = (navigator.deviceMemory ?? 8) <= 2;

if (slow || lowMemory) {
  document.documentElement.classList.add("lite");
}
```

## Những thứ nên hạ cấp

- Video nền → ảnh tĩnh
- Animation phức tạp → tắt
- Bản đồ tương tác → ảnh chụp + link

Quan trọng nhất: bản "lite" vẫn phải có đầy đủ **nội dung**.
