## Vấn đề của mật khẩu tĩnh

Mật khẩu nằm trong `.env` hoặc biến môi trường thường sống hàng năm, được chia sẻ giữa nhiều service và rất khó xoay vòng.

## Dynamic secrets

Vault có thể **tạo user database theo yêu cầu**, kèm thời hạn (TTL). Hết hạn, user tự bị thu hồi.

```bash
vault secrets enable database
vault write database/roles/blog-app \
    db_name=blog \
    default_ttl=1h max_ttl=24h
```

## Lợi ích

- Mỗi instance có credential riêng → dễ truy vết
- Rò rỉ một credential chỉ nguy hiểm trong thời gian ngắn
- Xoay vòng tự động, không cần deploy lại
